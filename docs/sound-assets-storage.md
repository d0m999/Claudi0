# 生成记录与命名草稿的持久化

对应 ADR 0026、声音重设计规格 #217。`PanelAppComposition` 组装 app-lifetime 协调器和记录存储，界面借用同一个包编辑 owner 与草稿存储。关闭设置只结束界面采用上下文和手动试听。

## 已保存生成记录

私有数据根下的 `generation-history/` 与 `packs/`、AI 临时目录、凭据相互独立：

```text
generation-history/
  .store.lock
  <generation UUID>/
    batch.json
    <audio UUID>/
      audio.json
      audio.mp3
```

每批只保存一次原始描述、生成时间、实际 profile ID，以及存储版本、稳定 ID 和初始音频身份集合。每条保存显示名称、校验所得时长、格式、字节数和 SHA-256。名称不是路径。没有工作区身份、Provider request ID、远端 URL、凭据、采用凭证、内部方案或完整请求正文。描述属于用户私人创作内容，不进入日志或诊断导出。

有效批次先完整写入私有 staging，再原子独占发布。以稳定生成 ID 读回确认已完成的发布，重试不创建重复组。只有归档成功后，当前仍有效的表单才能采用候选。采用结果是包内独立副本；历史改名和删除不影响该副本。

列表只读元数据，播放或采用时才读取、验证音频字节。目录枚举、记录读取和写入在后台串行执行。损坏条目显示不可用，不妨碍健康记录。根读取失败保留上次成功列表并提供重试。记录没有自动清理期限。

单条删除直接移到系统废纸篓；整组删除确认执行时的实际数量；最后一条删除一并移动组目录。先隔离目标，再调用系统 Trash；失败尝试恢复，恢复失败保留隔离对象并显示可找回位置，绝不改用永久删除。系统废纸篓找回不承诺重建记录索引，找回的音频可作为本地文件重新导入。

## 在途任务与未保存结果

全应用只接受一个生成任务，不排队。请求冻结描述、locale、profile、路线政策及同一绝对截止时间。关闭表单、切页、切服务、关闭设置不重新请求，也不取消在途生成。切服务只影响下一次生成；主动取消仅停止本地等待，迟到结果不能恢复旧采用资格。

保存失败保留有效临时音频；可试听、重试本地保存，或确认数量后逐项移到废纸篓。部分 Trash 失败继续保留剩余项，阻止新生成。重试保存不调用 Provider 或重新下载。常规退出根据生成中或尚未保存状态提示，并合并重复退出请求。已保存记录和命名草稿可跨重启恢复；未保存结果不承诺崩溃、强退或重启恢复。

## 命名草稿

`sound-pack-drafts/<packID>.json` 仅保存版本、稳定 pack ID 和名称，不属于已安装声音包扫描根。确认名称才创建记录，多个草稿可同时存在。名称 trim 后非空，最多 64 个 Swift `Character`，拒绝控制字符及换行；在 `packs.lock` 内重新对内置包、用户包及草稿做大小写和字符宽度避重。

首次成功绑定通过既有隐藏 staging 和独占发布事务安装同一 ID、同一名称的包。失败保留草稿；发布后若登记清理未完成，刷新先依据安装包的同一身份抑制重复投影，再清理登记。已发布包即使被清空也保持已安装状态。旧同名包不迁移。

升级从空生成记录库开始，不把旧临时目录冒认为历史。降级或 Provider 隐藏不删除现有记录。配置 schema、旧包、宿主配置、receipts 和凭据位置不因本功能迁移。
