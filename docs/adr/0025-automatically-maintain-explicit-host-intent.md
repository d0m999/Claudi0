# 自动维护来源接入，显式关闭优先，退出暂停新事件

依据用户确认的集成自动化与设置改版计划，正式来源 Claude Code、Codex、WorkBuddy 在首次启动、
首次升级及后续发现安装时自动开启并准备。唯一共享意愿保存在原有 config 中：
`host_integrations.policy_version = 1`，`surfaces[HostSurfaceID] = { enabled, revision }`。
每次意愿改变使用新 UUID；重复相同写入幂等。未知字段、未来来源、声音设置与首次迁移备份保留；
损坏或权限失败拒写及拒收，不能猜测为开启。新增来源继续遵守 ADR 0024 的证据门槛。

选择默认自动接入，是为了免去已安装来源的手动配置流程。显式 OFF 优先于升级、重装和修复，
防止用户反复关闭被后台打开。关闭先可靠保存意愿，再收起该来源横幅并清理自有 hooks；清理失败
仍然关闭。历史活动、回执、已接受提醒的 TTL、冻结阅读集合与主动导航保留。

新增独立于提示接收器的 GUI 运行注册：运行 UUID、PID、内核启动秒/微秒及用户身份。
进程死亡、zombie、PID 复用、注册损坏或无法验证时拒绝新事件；无需 daemon 或心跳。
正常退出按运行 UUID 撤销，hooks 与启用意愿保留，下次启动恢复。已启动的短提示音自然结束，
暂停期间的新事件不记录、不补播。这明确替代 ADR 0012 的退出后仍播放、写回执及计数合同。

hook 在入口捕获意愿 revision 与 GUI 运行身份。短期发布许可与意愿最终写入、运行撤销共用
`host-authorization.lock`，结果为 allowed / stale / busy / unavailable。配置最终发布与 marker 激活
共享许可；旧安装不能覆盖新 OFF，旧清理不能删除重新开启后的接入。活动提交/暂存、去重消费、
回执发布、音频启动和通知发送分别复验。许可内禁止版本探测、bootstrap、备份、await 或等待播放结束。
已经合法提交或暂存的活动可以成为历史；被拒绝的事件不能进暂存队列。

维护由 app 生命周期持有，每来源独立执行，250 ms 合并、60 秒发现兜底，安全锁忙按 1/3/10 秒
有限重试。永久配置错误保持原内容并报告，耗尽后等待事实变化或显式重试。设置窗口和页面关闭不
影响维护；无真实回执不是重装条件。安装发现使用真实可执行文件与版本，以及 WorkBuddy 的应用身份，
不以配置目录存在证明安装。共享 runtime 准备失败时不得写宿主配置或显示就绪。

设置保留一个 retained window 与 typed history，采用应用列表 → 应用详情 → 诊断详情。
开关只读取已保存意愿；状态分别为未安装、已关闭、正在准备/更新、接入已准备好、已收到事件或有证据的
阻断原因。缺少回执或等待时间不产生授权要求，`/hooks` 只作诊断帮助。声音继续属于默认组/工作区。
`HostEventNotice.intent_revision` 是 schema 1 的可选解码字段；新版生产接收入口及最终 reducer 拒绝
缺失、非法或不匹配值，导航准备返回再次复验，复制和 8 KiB 降级保留该字段。

代价是 GUI 与含门禁的 helper 必须同版本交付，旧 helper 的行为不能由新 GUI 单独改变。
自动检查、原型、原生键盘/VoiceOver、真实宿主与听音证据分别记录。
完整规格与验收边界见 [实施规格](../../plan/PLAN-INTEGRATION-AUTOMATION.md)。
