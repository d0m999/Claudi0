# 将严格签名检查和版本缓存填充移出 hook

2026-10-10 的设计评审提出：`HostVersionResolver` 保持版本观察缓存的唯一 owner，但 hook 只复用
逐次验证合格的观察，未命中继续原有有界真实版本探测，不再做签名冷填充或续期。完整内容与厂商签名检查
及合格缓存发布仅由显式刷新入口执行，在连接/修复的既有事务与发布许可结束后，或用户明确选择的版本刷新诊断中调用。
这是用有限的命中覆盖换取可预测事件路径的候选。用户已单独授权 E1 的本地实现与隔离验证；
生产接线、维护触发和本 ADR 的整体接受均未获授权。

本提案拟局部调整 [ADR 0031](0031-measure-hooks-before-changing-execution-policy.md) 的填充位置和
“版本诊断强制探测刷新”的含糊边界；接受后再为原 ADR 添加日期与引用。强制取得真实版本和缓存刷新分离：
被动发现、状态/快照及默认 `doctor` 保持原只读合同，不触发签名填充。缓存资格、实际版本来源、原调用路径、
身份前后复验、严格签名 flags、600 s 有效期上限、每宿主四项、私有有界原子发布及失败关闭不放宽。
版本缓存命中仍不构成当前激活，也不替代 installation、启用意愿及 GUI 运行身份。

刷新由既有生命周期 owner 监督，阻塞签名在 utility 执行器运行，不持有事件发布许可或原连接事务锁。
每宿主非阻塞刷新 operation lock 与短期缓存写锁分开；旧观察撤销、探测失败、竞争及迟到发布须隔离验证。
签名检查可能继续很慢，取消不得被误报为已中断底层检查；合格版本不因缓存发布失败被丢弃。
不增加 TTL timer、命中续期、hook 驱动修复、daemon、看门狗或放宽签名的替代路径。

代价是连接/修复需承担独立刷新工作，已有完整连接的启动不保证填充，600 s 到期后 hook 连续恢复探测，
直到下一次合格刷新。不能只测预填充后的命中，须计入整个刷新周期的探测、签名和发布成本。
详细接口、触发、并发与分步实验见 [设计评审](../performance/hook-version-cache-refresh-design-review-2026-10-10.md)。

本提案不启用生产缓存，不确认生产冷预算；宿主策略和回执热路径继续暂停，现有回执历史和活动计数不动。
ADR 0005 的 Git 算法/共同仓库身份、ADR 0025 的接收资格和发布许可、ADR 0032 的 arm64-only 范围，
以及原性能/体积门禁全部不变。本轮只实施 E1；结果与后续建议见 [E1 报告](../performance/hook-cache-refresh-e1-2026-10-10.md)。
通过实验不等于接受本 ADR 或正式验收，E2 不自动开始。

## E1 本地接口

`resolve(.reuseValidated)` 验证合格观察后复用，未命中只按原路径真实探测；
`resolve(.forceProbe)` 忽略缓存真实探测，不填充和续期。失败的 hook miss 可在短写锁内撤销
它实际读取的旧观察，但不能创建缓存根或删除更新的刷新结果。默认发现和诊断保持无缓存工厂。

独立 `refresh(host, isCurrent:)` 返回规范化版本与类型化缓存结果，区分已发布、跳过、探测失败、
不具资格、身份变化、过期及取消。每宿主 operation lock 全程非阻塞，短写锁只围住撤销和原子发布；
签名期间不占短写锁。版本观察时间取探测完成时刻，签名耗时不续期。新观察附加独立标识，
避免时间戳相同时迟到失败删除更新结果；schema 1 仍可读取旧条目。新旧 writer 不并发共用根。

生命周期回调仅在 E1 中验证为发布前检查点，阻塞 Security 调用仍不可通过该回调强制中断。
GUI/manager 的 utility 调度、OFF/退出代次和真实维护触发属于未授权的 E2。

2026-10-11 E1 默认规模隔离测量已补齐：未命中零签名、严格刷新及后续命中计数正确，
但 Core bypass 和真实签名后命中仍有超限，严格刷新最大观测值为 2.906 s。
详见 E1 报告；不接受完整提案、不冻结生产冷预算，也不进入 E2。

2026-10-11 收束决定：用户结束 E1 并停止追加长尾诊断，候选源码与失败证据保留。
隔离正确性和体积证据不改变性能未全部通过、历史长尾来源未知及周期收益未验证的判定。
本 ADR 继续为 proposed；生产默认关闭，E2、宿主策略及回执第三阶段继续暂停。
固定评审材料和最终边界见 [E1 收束报告](../performance/hook-cache-e1-closeout-2026-10-11.md)。
