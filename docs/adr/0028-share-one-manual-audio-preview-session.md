# 共享一个手动试听会话

2026-10-08，用户确认已有声音页、面板和默认组／工作区试听统一支持播放／停止，并且全 App 同时只试听一条。各界面独立播放器容易重叠，也无法让停止状态对应真实播放。代价是将现有声音页播放仲裁提升为应用生命周期共享 owner，所有来源需提供生命周期身份。

## 决策

`ManualAudioPreviewSession` 唯一持有手动试听的请求、播放与连续试听资格，借用一个注入播放器。新请求先停止旧声音，并撤销旧异步准备和整段序列；迟到回调不得改变新状态。来源关闭只撤销属于该次来源身份的请求，不能停止之后其他来源的试听。

文件安全解析、组音量和播放资格仍由现有领域 owner 提供。声音页以相对增益 1 播放；面板、组详情及连续试听每次启动使用当前组增益，已播放音频不随滑块实时改增益。真实播放器 completion 决定自然结束，调度计时不能假造播放事实。

连续试听保留已有入口与事件顺序；停止、其他试听接管或离页撤销整个序列。面板关闭、设置目的页离开、表单关闭、设置窗口关闭或显式隐藏停止相应试听；失去 key 或普通遮挡不视为离页。

自动事件声音继续走既有独立链路。此决策不增加试听入口，不修改绑定、配置、持久存储或 Provider 合同。动效仅消费事实，不维护第二份播放状态。
