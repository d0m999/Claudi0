# 每组逐事件选择本机 macOS 系统提示音

> 本文为历史决策，已由 [ADR 0021](0021-own-all-event-sounds-in-packs.md) 取代。旧组级字段保留并停用。

默认组与每个工作区仍各自拥有一个声音包、音量和五个事件开关，同时允许为单个公共事件选择一个本机 macOS 系统提示音。未设置系统音的事件使用该组声音包；系统音的选择只存名称，运行时从当前系统取得并验证音频，不复制到声音包、仓库、安装包或备份。选择的系统音失效时该事件停止播放并显示原因，不回退到包音，以免播放与用户所选不符。

逐事件选择放在已有声音作用域的配置与播放解析入口内，保留现有接入、动态静默、去抖、音量、试听和回执边界。系统音不是 `SoundPackLibrary` 的已安装声音包；包库继续只拥有包磁盘事实。选择声音与关闭事件仍是两个独立动作。这个模型允许同一组混用包音与系统音，代价是配置和设置详情须明确表示每个事件的来源。选择系统音前，GUI 核对应用内置 helper 与已安装 helper 是同一可执行文件；尚未完成更新时拒绝新选择，避免旧 helper 忽略字段后误播包音。已有选择遇到外部降级仍须通过接入诊断与发布验证发现，不能由配置格式单独阻止旧程序忽略未知字段。

Apple 的 [AppKit `NSSound.init(named:)` 文档](https://developer.apple.com/documentation/AppKit/NSSound/init%28named%3A%29)支持按名称在运行时取得系统声音。GUI 与 Foundation-only helper 分别通过运行时预览和 macOS 自有声音目录读取本机音频；后者沿用已有异步 `afplay` 播放路径。该 API 说明不构成音频文件的再分发许可，因此仓库、声音包与安装产物只保存名称，不纳入系统音文件。
