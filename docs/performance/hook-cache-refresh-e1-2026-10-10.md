## 实现合同

- `resolve(.reuseValidated)` 每次重新定位并验证身份；合格观察命中后不探测、不签名。
  空、过期、损坏、身份变化及不合格布局只走原有有界真实探测，不签名、不创建缓存根、不填充或续期。
- `resolve(.forceProbe)` 始终真实探测，不读取观察、不签名、不发布或续期。默认发现、状态与 `doctor`
  保持无缓存工厂和既有只读边界；没有新增生产 CLI flag 或 GUI 入口。
- 唯一显式 `refresh(host, isCurrent:)` 分别返回规范化版本与类型化缓存状态。缓存关闭/未知布局保留真实探测；
  资格或安全发布前提不足、operation lock/撤销写锁忙时可跳过。成功版本不会因签名不合格或发布失败被丢弃。
- 每宿主非阻塞 operation lock 覆盖完整刷新，短写锁只覆盖撤销与发布。签名前撤销将替换的旧观察；
  探测、签名及最终发布前复验依赖身份和生命周期检查点。取消不承诺中断同步 Security 调用。
- 观察时间取探测完成时刻，签名耗时计入年龄；600 s 上限、每宿主四项、0700/0600、16 KiB、有界原子发布、
  厂商 requirement 与 `kSecCSCheckAllArchitectures | kSecCSStrictValidate` 全部不变。
- 失败 hook miss 只撤销它实际读到的旧观察。新增可选观察标识区分相同时间戳下的新刷新，迟到失败不能删除新观察。
  schema 1 与旧 reader 的双向读取已验证；不允许新旧 writer 并发共用实验根。

[ADR 0031](../adr/0031-measure-hooks-before-changing-execution-policy.md) 记录本轮局部实验授权；
[ADR 0033](../adr/0033-refresh-host-version-cache-outside-hooks.md) 仍为 proposed，完整架构和生产触发尚未接受。
