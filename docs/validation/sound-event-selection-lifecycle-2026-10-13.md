# 包事件声音选用生命周期收拢

范围为 2026-10-13 架构评估候选 02；实现基点 `9e408d62206d2411a5005377aff8ea6e56055537`。
沿用声音设置重设计 D17、D25、D31、D34、D39、D41、D45，以及 ADR 0016、0021、0026、0028。
本次实现不改变声音页的视觉布局、音频格式、数据路径或组的选包语义。

## 生产 interface 与所有权

`SoundPacksEditorOwner.soundSelection` 持有 `SoundEventSelectionSession`。五类来源统一从
`begin(event:mode:)` 捕获包、公共事件及完整原映射。View 保留选项、文件选择器和呈现；
设置 session 保留路由与导航，结束协作由编辑 module 执行。

- `SoundPacksEditorOwner` 继续独占写入资格、包锁／CAS、导入绑定与事务结算。
- `AICueGenerationCoordinator` 继续持有后台生成、归档、待处理结果与采用 lease。
- `GenerationHistoryStore` 继续持有生成记录；历史再次选用取得新的音频 proof。
- `ManualAudioPreviewSession` 继续唯一持有试听请求、播放及来源身份。
- `SoundPackLibrary` 继续唯一持有磁盘观察与刷新，未新增扫描或缓存 owner。

module 同步撤销选用与异步请求，停止属于自身 origin 的试听，再在 MainActor 外释放私有暂存。
首次打开明确表单时，可接入旧深链已呈现的同包同事件 composer，但由 editor 签发全新选用上下文；
已有选用切换、关闭重开、不匹配路由和只读复制入口均结束旧 composer，不恢复旧凭证。
本机预览冻结已验证字节，选用不重新读取外部源文件。历史试听的读取、暂存与旧资源释放均复验
同一播放 token；迟到成功释放资源，迟到失败不给新表单制造错误。

## 时序合同

| 动作或变化 | 合同 |
| --- | --- |
| 打开五类来源表单 | 新的一次性 `packID + Event` 上下文，替换旧资格 |
| 选择或试听 | 不绑定事件，不改变组的选包 |
| 显式选用 | 使用原包级事务；每次写入重新验证完整来源 |
| 同路由刷新 | 保留仍打开的选用上下文 |
| 离页、关闭、切换包或事件 | 旧上下文不再可写，返回原目标也不能复活 |
| 同一草稿首音成功发布 | 使用 writer 确认的短期呈现资格，允许 `draft → pack`，不中断本次完成反馈 |
| 设置关闭后迟到的 sheet dismissal | 拒绝整次旧操作，不能通过重新激活终止接管者 |
| 目标失效 | 撤销选用与旧试听请求，重复失效仍保留原表单关闭能力；仍挂载页面在同路由恢复后允许新的显式试听 |
| 关闭 AI 表单 | 原生成继续归档，旧采用凭证失效；不重复请求、播放或自动采用 |
| 保存重试 | 仅归档当前有效音频；只有仍打开的当前表单可恢复采用资格 |
| 已接受的异步写入 | 原 owner 结算；迟到结果不能导航或改写新表单反馈 |

首音发布的异步导入采用已有 `finishPublishedDraft` 路径，等待共享库观察时保留目标浏览身份；
没有另建刷新或写入链。现有音选择的拒绝继续显示实际写失败或“声音已变化”，不把资格失效
推断成存储故障。
