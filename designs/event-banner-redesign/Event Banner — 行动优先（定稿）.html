01内容规范（第一性原理）

横幅只为一瞥存在：回答「要不要现在切过去」，不承载「以后再看」的信息。因此 主行 = 宿主 + 用户语言动词短语，副行 = 项目名 + 年龄短码（<1分 / 2分 / 3时 / 2天）， 详情 = 绝对时刻 + 相对长式——年龄双轨：一瞥轨只答「这条还新鲜吗」，详情轨才给可复制的精确时间。 会话短 ID 从一瞥界面降级到详情。 阻塞类（授权 / 输入 / 审查 / 中断）带事件色脊柱与动词 chip；瞬时类（本轮结束 / 子任务结束 / 即将提问 / 任务开始） 整体降一级且零按钮——它不需要你做任何事。用英文切换可验证 440pt 内文案不溢出。

07动效

Claudio 的 Motion 有一条红线：个性来自时序，不是杂音，且明写「不引入常驻 EQ 或无限循环动画」。 因此 Open Island 那种 0.7 秒无限呼吸在这里是违规的，一个都不采用。 本稿只加三类动效，且每一条都绑在一个已经存在的模型事实上：剩余时间轨表达「还剩多久消失」、悬停暂停表达已有合同里的「悬停即暂停剩余阅读时间」、 字形节拍脉冲沿用既有「音频实际播放后执行一次 1.0→1.12→1.0」决议。

06验收边界（不因本次设计稿宣称已过）

  • 自动化：GUI / helper executable harness（swift run --package-path gui claudio-gui-tests）+ --event-attention 专项；投影新增动词分支需补用例，含瞬时与过期。
  • 真实挂载：英中 × 浅深 × 0/1/5/7/50 项、末行滚动、300×180pt 详情、滚动后真实点击与失败反馈——自动化不代替。
  • 对比度：事件色仅用于脊柱 / 字形 tile / chip 等图形与小面积；正文一律 text / text-2，由 ContrastSuite 逐对数学断言钉死。
  • 无障碍：IME 组字、FKA 下 Tab/Shift-Tab/Enter/Space/Esc、VoiceOver 动作与反馈逐项人工验收；accessibilityIdentifier 沿用既有身份，不重命名。
  • 模型合同不变：瞬时 4 秒自动释放、待接手最多 50 项 / 每项 30 分钟、悬停与键盘聚焦暂停剩余阅读时间、精确返回确认才移除。
  • 体积：折叠高度变化后仍需过 check-release-size.sh 现有预算。
