claudi0 可沿用的两版 macOS 原生骨架

两版各自锚定一条真实的 macOS 原生参考（官方 HIG / 系统 App 与第三方精品），覆盖四个界面：统一设置窗口、菜单栏主面板、顶部事件提示、首次运行引导。 五事件语义色与黏土品牌色在两版中保持不变——它们是 claudi0 的语义层；变的只是外壳骨架与材质。

原版参考链接

A 系统设置骨架

主锚：Apple 系统设置的「侧栏 + 详情 + 工具栏」三件套，几何与分组完全照抄官方范式。

  • HIG · Sidebarssource list 分组、半透明侧栏、选中态
  • HIG · Toolbars工具栏常驻、标题、搜索框位置
  • HIG · Settings重开回到上次 pane、窗口标题 = pane 名
  • HIG · WindowsmacOS 窗口结构与最小尺寸
  • macOS TahoeLiquid Glass：更圆的窗口、透明菜单栏、玻璃侧栏

B 控制中心浮层

主锚：macOS 控制中心与菜单栏工具的浮层语言——玻璃材质、模块 tile、紧凑分段控件。

  • HIG · Popovers瞬态浮层、不阻塞、箭头锚定
  • HIG · The Menu BarMenu Bar Extras：复杂功能才用 popover
  • Bartender 5菜单栏项的收纳与 popover 呈现
  • Ice菜单栏布局 + 可搜索的玻璃设置窗
  • Raycast玻璃浮层、键盘优先、分段与 tile 密度

为什么是这两条：A 解决「八个目的页怎么装下还不显得重」，B 解决「312pt 面板与 440pt 提示怎么不撞车」。 两版互斥的是外壳（骨架与材质），共享的是 claudi0 的语义层（五事件色、黏土品牌色、试听/静音正交、写失败与读失败分离）。
