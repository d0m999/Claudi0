一、使用起点

先阅读 04-spec/quick-spec.html 或 quick-spec.pdf，再按背景、尺寸和输出方式选择正式素材。项目使用范围草案见 LICENSE-usage.txt。

品牌名称写作 claudi0，全小写，结尾是数字 0。正式字标由自定义矢量路径构成，不是使用现成字体重新排出的文字。请直接使用交付字标，保留字形、字距和比例。

主标志为独立图形与 claudi0 字标组成的横向组合。logo-mono-black.svg 和 logo-mono-white.svg 同样是完整横向组合，不是独立小图形；独立图形请用 logo-mark 系列。

三、C1 色值与背景选择

酸柠  Acid Lime  #D8F447  RGB 216 / 244 / 71
深墨  Deep Ink   #172B25  RGB 23 / 43 / 37
暖白  Warm White #F5F3E9  RGB 245 / 243 / 233

以上为 sRGB 屏幕色值。相对对比度：酸柠/深墨 12.03:1，暖白/深墨 13.40:1，酸柠/暖白仅 1.11:1。酸柠彩色 SVG 和透明 PNG 应放在深墨背景上。透明不等于自带深色底；在浅色预览器或浅色页面上直接打开时，酸柠可能不够清楚。

浅底优先使用纯黑单色横向组合；如需深墨色版本，应按照规范以 #172B25 对矢量整体统一换色，不改变形状、字距或组合关系。深底可使用酸柠彩色版本或纯白反白横向组合。不同背景下的使用方法以 04-spec 为准。

不要拉伸、压扁、旋转、重排组合、替换字标、改变负形开口，或添加描边、阴影、渐变等效果。安全空间、最小尺寸和错误示例见 04-spec。

四、制作与验收边界

1. 字标与辅助文字
正式 claudi0 字标为自定义路径。规范中的辅助排版可使用 Outfit 与 Noto 字体制作，但成品文字已转为路径；HTML 不嵌入字体软件。本包不附可安装字体、网页字体或字体子集，字体来源说明见 LICENSE-usage.txt。

2. 印刷文件
文件名中的 print 表示用于制作沟通的矢量稿。PDF 仍按 sRGB 制作，不是经 ICC 校准的 CMYK 印刷认证文件。彩色 PDF 的深墨背景用于正确呈现酸柠。CMYK 参考值如有提供，仅是数学近似，不代表指定纸张、油墨或设备上的实际印刷结果。批量印刷前需由供应商根据工艺转换、打样，并确认出血、裁切和颜色。

3. 小尺寸与 favicon
16 / 24 / 32 px 比较图是静态检查参考，不代表浏览器已接入验收。实际静态图中，16 px 仍能看出两块轮廓，但阶梯切缝的转折弱于 24 / 32 px；常规独立标志优先 24 px 以上。favicon 为小尺寸将图形占比调至画布 75%，只改变统一缩放，不修改 T2 路径；App 与 apple-touch 保持 63%。favicon 需要独立检查实际显示效果，并在目标浏览器的标签页、收藏夹及不同显示密度下确认。不要用放大预览代替原尺寸检查；ICO 含两种尺寸，也不等于覆盖所有系统需求。

4. App 图标
app-icon-1024.png 外部圆角区域透明；apple-touch-icon-180.png 为不带预制圆角的全不透明方形，避免与平台遮罩叠加。本包提供平滑圆角视觉素材，不含 macOS .icns、完整 AppIcon 资源集或已接入的应用配置。不同平台的遮罩、透明度与裁切规则仍需核对，避免重复圆角或意外裁切。不得将这份通用素材理解为已通过平台上架审核。
