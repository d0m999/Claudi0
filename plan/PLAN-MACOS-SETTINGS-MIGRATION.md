## 实施约束

复用 `SettingsRootView`、`SettingsPresentationSession`、`SettingsPresentationDependencies` 与现有 owner。详情类型仅拥有呈现状态；`SettingsRoute`、raw values 和深链保持兼容。定向返回捕获并重验稳定身份。不得新增 Swift 公共 API、存储字段、配置合同、第二个声音扫描 owner 或并行窗口。

默认／最小内容区 1240×820／960×640 pt；侧栏在窗口 ≤1100 pt 时为 210 pt，否则 252 pt，三组间距 24 pt。单列最大 780 pt，含左右 32／26 pt 内边距。section 28 pt，group 16 pt，圆角 10 pt，普通／多行最小 48／61 pt；长文本自然增高。主底白／`#202022`，功能组 `#F5F5F7`／`#2D2D30`，侧栏 `#E9E9EC`／`#2B2B2E`。默认系统字体及蓝色 accent，不继承 Rounded；每页固定页头、单个主滚动区、单层详情。

声音事实由 `SoundPackLibrary` 持有；组写入由 `PanelConfigController` 持有；包写入由 `SoundPacksEditorOwner` 持有。固定五 profiles、Keychain／SenseAudio 私有本地文件、active／pending 政策及现有 1000／64／40 字符校验不变。官方产品原图放在既有 GUI 资源包，通过 package 注入；设置 target 不拥有资源。

## 验证与完成定义

在真实 `SettingsRootView`／session／dependencies 接缝挂载，复用隔离 DEBUG fixture。操作后读取实际临时数据、最新 AX、保留值、失败原因及恢复入口；控件不唯一、超时或结果缺失算失败。

八页 × 两语言 × 两外观 × 两尺寸共 64 个原生布局组合，采集实际窗口尺寸、页首及滚动末尾，检查颜色、列宽、字体、分组、长文本、错误、可达和横向溢出。详情与 sheet 补正常、进行中、失败与禁用状态。C01–C48 全部须有生产映射与验收证据。

运行 helper／GUI executable harness、GUI Debug／Release、设置 target、bundle／大小、本地化／格式／diff 检查。同一 SDK 记录版本；工具链失败独立记录。固定基线 `verify-settings-experience.sh` 要求干净且已提交候选；未授权提交时不得清理共享工作树或制造干净状态，应记录未完成。

完整原生人工验收包括逐页可读性、真实 Tab／方向键／Escape、sheet 取消、焦点归还、VoiceOver 名称及顺序、关闭／再展示及菜单交互、真实本地与系统声音和候选试听、音量／停止／失效反馈。旧 SenseAudio 风险接受不覆盖本次呈现。自动化、原型、人工、外部证据分别报告；未完成保持可见。
