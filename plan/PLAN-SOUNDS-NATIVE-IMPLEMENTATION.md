## Problem Statement

声音页混合包编辑与工作区配置，生成任务随表单结束，未采用结果与空草稿不能持久保留。用户难以区分试听、选择、保存与生效。

## Solution

执行 2026-10-08 已批准的声音重设计 D1–D55：声音包列表→同区域五事件详情，所有有效生成先保存到独立本地生成记录，命名草稿持久保留，后台生成独立于表单，所有采用必须明确确认。唯一规范原型为 Panel and Settings Prototype，领域依据 ADR 0001–0006、0008、0011、0014–0016、0021、0022、0026 的现行合同。

## User Stories

1. 作为用户，我希望声音页先显示包列表，以便找到目标包。
2. 作为用户，我希望在同区进入详情，以便沿用原生导航。
3. 作为用户，我希望移除工作区设置和使用者信息，以便专注声音。
4. 作为用户，我希望浏览、复制、编辑不改组选包，以便自行应用。
5. 作为用户，我希望五个事件直接呈现，以便快速编辑。
6. 作为用户，我希望空项显示设置、已有项显示更换，以便理解状态。
7. 作为用户，我希望统一选择 AI、历史、本包、导入和系统音，以便操作一致。
8. 作为用户，我希望清除直接在事件行，以便快速解除绑定。
9. 作为用户，我希望清除保留文件和历史，以便复用。
10. 作为用户，我希望明确选用后立即保存，以便无需整页提交。
11. 作为用户，我希望失败保留原绑定并显示原因，以便重试。
12. 作为用户，我希望新建先命名，以便识别草稿。
13. 作为用户，我希望草稿跨离页、关窗、重启保留，以便继续创作。
14. 作为用户，我希望首次成功绑定才发布，以免选中空草稿。
15. 作为用户，我希望清空已发布包不退回草稿，以便继续使用。
16. 作为用户，我希望内置包先复制并编辑，以便保护原包。
17. 作为用户，我希望复制先命名、成功后进入副本，以便明确目标。
18. 作为用户，我希望改名保留包身份和引用，以便整理。
19. 作为用户，我希望新命名对内置、用户和草稿避重，以便减少混淆。
20. 作为用户，我希望旧同名包不自动修改，以便无损升级。
21. 作为用户，我希望整包导入后可编辑，以便利用现有素材。
22. 作为用户，我希望包删除显示保护原因，以免删除使用中的包。
23. 作为用户，我希望看到通用共享后果说明，以便理解影响。
24. 作为用户，我希望本包选择显示文件和占用，以免重复绑定。
25. 作为用户，我希望选择不自动试听，以便控制播放。
26. 作为用户，我希望本地导入先预览再选用，以免误覆盖。
27. 作为用户，我希望取消导入保留源文件和旧绑定，以便放心比较。
28. 作为用户，我希望系统音显示真实可用性，以便正确选择。
29. 作为用户，我希望 AI 附属表单显示固定目标、服务和描述，以便确认用途。
30. 作为用户，我希望看到实际有效候选数，以便比较结果。
31. 作为用户，我希望根页和表单复用服务管理，以便统一配置。
32. 作为用户，我希望凭据保存不自动生成，以便控制费用。
33. 作为用户，我希望全部有效结果归档，以便复用未采用项。
34. 作为用户，我希望历史按批次显示描述、时间、服务和时长，以便追溯。
35. 作为用户，我希望后续描述和服务变化不改旧记录，以便保持真实来源。
36. 作为用户，我希望历史改名不改包内副本，以便独立整理。
37. 作为用户，我希望记录长期保留并手动清理，以便自主控制。
38. 作为用户，我希望单条直接、整组确认数量后移到废纸篓，以便恢复误删。
39. 作为用户，我希望最后一条删除时移除空组，以便保持整洁。
40. 作为用户，我希望历史删除不影响包内副本，以便独立清理。
41. 作为用户，我希望历史选用先固定目标事件，以免误绑定。
42. 作为用户，我希望记录管理页不提供采用，以免误改声音。
43. 作为用户，我希望关窗或离页继续生成，以便处理其他事情。
44. 作为用户，我希望记录入口显示进度和结果，以便找回任务。
45. 作为用户，我希望后台完成不自动打开、播放、采用或通知，以免打扰。
46. 作为用户，我希望全应用单任务、无队列，以便理解费用。
47. 作为用户，我希望切服务只影响下次生成，以便当前任务继续。
48. 作为用户，我希望取消停止本地等待并保留描述，以便修改重试。
49. 作为用户，我希望再次生成收起旧候选，以免混淆。
50. 作为用户，我希望保存失败仍能试听并本地重试，以免重复请求。
51. 作为用户，我希望关闭后仍能处理未保存结果，以便稍后恢复。
52. 作为用户，我希望处理完待保存结果才允许新生成，以免累积。
53. 作为用户，我希望放弃待处理先确认数量并移到废纸篓，以便恢复文件。
54. 作为用户，我希望退出前知道未完成或未保存内容，以便决定等待。
55. 作为用户，我希望附属表单管理包内文件，以便整理素材。
56. 作为用户，我希望已绑定文件受保护、未使用文件确认后进废纸篓，以免误删。
57. 作为用户，我希望试听可切换停止且一次一条，以便控制声音。
58. 作为用户，我希望声音页使用系统输出音量，以免受组音量影响。
59. 作为用户，我希望离页立即停止试听，以免持续出声。
60. 作为用户，我希望双语、键盘和 VoiceOver 语义一致，以便完整使用。

## Implementation Decisions

- P0 合同收口；P1 GenerationHistoryStore；P2 app-lifetime AICueGenerationCoordinator；P3 SoundPackDraftStore、统一命名、复制、改名及整包导入；P4 统一选用事务；P5 试听和 Trash；P6 原生页面、路由、本地化；P7 整体门禁。
- PanelAppComposition 保留唯一 SoundPackLibrary 和 SoundPacksEditorOwner，组装唯一生成协调器及记录、草稿存储；表单只持有展示和采用上下文。
- 文件式历史与草稿在现有私有根下独立命名空间。历史只持久保存稳定身份、原始描述、生成时间、实际 profile、名称、受控相对定位、实测时长及必要存储元数据。不得保存内部计划、请求正文、远端 URL、凭据或工作区。音频子项与组元数据分离。
- 有效批次私有 staging 后原子归档、按 ID 幂等；成功归档才允许采用。失败保留有效结果，重试不得请求 AI 或重新下载。读取和枚举在后台，按需读音频；损坏条目隔离，失败不假报空库。
- 全应用只有一个生成任务。冻结输入、profile、路线政策和原绝对截止时间。关表单、离页、关设置、切服务只撤销旧采用上下文；任务继续并归档。主动取消隔离迟到结果。生成中、归档中及待处理阻止新生成；无队列。
- 待处理可试听、重试或确认实际数量后移到废纸篓；失败剩余继续阻止生成。常规退出对生成中及未保存结果分别提示；不承诺退出后任务或未保存结果恢复。
- 草稿确认命名后持久保存，不进入已安装包、面板显示集或组选包。首个 AI、历史、本地或系统音经完整事务成功后原子发布同一 ID。清空已发布包不退回草稿。
- 名称 trim、非空、64 Character、无控制字符／换行；忽略大小写及宽度，在包锁内复查全部包与草稿。拒绝新重名，旧重名不迁移。显示名改动不改 ID、目录、文件、映射或引用。
- 复制先命名，成功才展示副本；复制及生成音频采用移除整包 license/author，保留独立 attribution 和未知字段。同步修正原型偏差。
- .claudiopack 定义为现有 manifest 和素材组成的 macOS 目录包，同时支持普通目录；无 ZIP。预览后确认导入，ID 冲突拒绝，不重写显示名或选包；安全读取、音频校验、staging 与包锁独占发布，失败不暴露半包。
- 事件来源统一捕获包／草稿、Event 和完整原声音来源；显式选用才经原有 import/bind、锁及 CAS 提交。历史使用新来源证明而非旧候选 permit。本地预览采用同一安全快照字节。导入失败保留原绑定，并如实反馈可能的未绑定文件。
- 历史采用复制独立文件，不依赖历史存续。单条直接 Trash，整组确认数量，最后一条移除空组，无应用内撤销。文件改名沿用 40 Character 限制，允许同名且不改物理身份。
- 包内管理仅查看／试听／未使用文件 Trash，无添加或分配入口；已绑定文件在锁内重读引用后保护。声音页仅通用删除保护原因，不暴露工作区信息。
- 一个声音页试听会话，播放器增益 1.0，跟随系统输出，不改系统音量；播放／停止、自然完成和失败由真实回调驱动，按播放 ID 隔离迟到回调；离页／关闭停止。面板和组详情仍按组音量。
- 唯一 retained 非激活 Settings 窗口、64 项窗口期历史。声音列表／包详情／草稿／历史采用 typed location；sheet 阻止外层导航，关闭恢复触发焦点。旧 editEvent/audio 转到新入口，copyAndApply 不再应用。声音页编辑不依赖当前组是否有效，删除仍完整验证引用。
- 新文本提供 en/zh-Hans 并注册 allKnown；稳定 AX ID。保留工厂恢复、Finder、许可和面板显示集能力。Swift 6/macOS 12，不新增框架、CLI 或组选项。

## Testing Decisions

用户已确认 A：核心集成为主。以现有 PanelAppComposition 隔离组装入口连接真实协调器、存储、owner 与事务，仅注入 Provider、vault、时钟、duration、Trash 和播放器。断言可观察状态、磁盘、请求次数与旧值保留；不复制实现逻辑。

复用 MenuBarCompositionSuite、AICueGenerationViewModelSuite、AICuePackScopedSuite、SoundPacksEditorAsyncOperationSuite、SoundPackImportBindTransactionSuite、UserSoundPackDeletionSuite 及 Settings 生命周期实践。覆盖完整／partial 生成、单任务、关闭继续、切服务、迟到结果、归档幂等与失败、待处理门禁、退出、记录恢复、独立副本、Trash 失败、命名竞争、草稿首次发布、整包安全导入、CAS、系统音独占、预览同字节、真实播放回调投影、路由、双语、隐私和 100 包性能。

最终执行 helper/gui executable harness、Debug/Release GUI build、localization JSON、Node 原型回归、diff/格式检查与干净候选统一设置门禁。原生人工验收分别记录双语、两种尺寸、外观、键盘、输入法、VoiceOver、焦点、真实音频、Trash 与重启。真实付费 Provider 仍须单独授权。自动门禁不等于真实系统或正式接受。

## Out of Scope

工作区及宿主协议重设计；云同步、分享导出、搜索、自动清理、配额、应用内撤销；并行生成／队列／退出后执行；新 Provider、任意 endpoint、凭据迁移或 fallback；ZIP、商店、音频编辑；全面 SwiftUI 状态重构；发布或旧 issue 自动关闭。
