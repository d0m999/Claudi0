# Spec：事件行「更换声音」入口与声音页拖放导入

> 来源：2026-10-17 grill-with-docs 讨论定稿（Q1–Q7 全决策见 Implementation Decisions）。决策证据为三个一次性原型（designs/panel-and-settings/ 下 `*-PROTOTYPE.html`）。

## Problem Statement

想换某个事件的提示音时，从面板出发没有直达入口：健康的事件行只有试听和静音，「配置声音…」恢复链接只在试听不可用（异常）时出现。用户必须走 齿轮 → 「声音」目的页 → 包 → 包详情事件行「更换…」→ 五选一来源 → sheet → 「选用」，实测 6–8 次点击，出厂声音包还要再加「复制并编辑」绕行。手头已有音频文件的用户同样要全程走菜单，不能把文件直接拖到目标事件上。

原始提案（右键菜单 + 面板行拖放）经事实核查后修正：右键菜单在 2026 年已被明确否决（不可发现 + 违反 WCAG 2.1.1 键盘可操作性）；面板的变更面被 ADR 0005 封闭（只选组、换包、调音量、试听、逐事件静音）；面板级 drop-zone 已被拍板删除（会产生孤儿文件）；导入/拖放/清除绑定被限定在声音管理面。本 spec 是与这些已拍板决定相容的收敛方案。

## Solution

从用户视角：

- **面板事件行**：声音文件名本身变成可点入口（链接样式，无菜单、无下拉箭头）。指针悬停显示 tooltip「更换声音…」（出厂声音包为「查看声音…」）；键盘 Tab 可聚焦、有焦点环；VoiceOver 读出动作与事件名。点击后统一设置窗口打开「声音」目的页并聚焦到该包该事件行；从声音页返回时恢复原来的作用域、音量、事件开关与事件焦点（return context）。出厂包下落点为只读查看视图，页内提供「复制并编辑」。
- **「声音」目的页包详情**：把音频文件拖到事件行上即开始导入——导入 sheet 直接以预览态打开（文件已装载），手动试听、显式点「选用」才绑定；取消或关闭保留旧绑定与源文件。拖起文件时事件行浮现目标高亮与「松开导入到『事件名』」浮标；不合规文件（类型/大小/时长/路径）被拒绝并说明原因。
- **可发现性**：用户声音包详情页常驻一行导向说明「五个事件的声音由本包提供。把音频文件拖到事件行上即可导入。」（先讲本页是什么，再顺带教捷径）；出厂包页不出现该行、拖起时行不亮目标框，松手得到与点击路径完全相同的「复制为我的包」引导。

## User Stories

1. 作为面板用户，我希望健康的事件行上有可见、可发现的「更换声音」入口，以便不必记忆 6–8 步的深层路径。
2. 作为面板用户，我希望点击事件行的声音文件名直接到达该事件的更换现场，以便跳转零导航步。
3. 作为键盘用户，我希望该入口可 Tab 聚焦且有可见焦点环，以便全程不依赖鼠标。
4. 作为 VoiceOver 用户，我希望入口的无障碍标签读出动词与事件名（如「更换声音，本轮结束」），以便理解点击后果。
5. 作为面板用户，我希望悬停文件名时 tooltip 显示「更换声音…」，以便链接意图不言自明。
6. 作为出厂包用户，我希望 tooltip 与落点都是「查看声音…」（只读视图 + 页内「复制并编辑」），以便不会误以为能直接改出厂包。
7. 作为面板用户，我希望从「声音」页返回时恢复我原来的作用域、音量、事件开关与事件焦点，以便换声音不丢失现场。
8. 作为面板用户，我希望面板行维持「图形、名称、声音名、试听、静音」的构成，以便面板保持轻量。
9. 作为用户，我希望包事件声音来源的写入只发生在「声音」目的页，以便行为可预测、只有一个真相来源。
10. 作为声音页用户，我希望把音频文件拖到事件行上即开始导入，以便省掉「更换…→ 导入音频 → 选文件」的绕行。
11. 作为声音页用户，我希望 drop 后先手动试听、显式「选用」才绑定，以便没听过的声音不会被绑上事件。
12. 作为声音页用户，我希望取消或关闭 sheet 保留旧绑定与源文件，以便试错零代价。
13. 作为声音页用户，我希望不合规文件被拒绝并给出既有分类原因，以便明白发生了什么。
14. 作为声音页用户，我希望拖起文件时事件行浮现目标高亮和「松开导入到『事件名』」，以便确定落点。
15. 作为不知道能拖的用户，我希望包详情页有一行说明提到这条捷径，以便在需要之前学会它。
16. 作为从不拖文件的用户，我希望这行说明首先讲清「本页是什么」（事件声音由本包提供），以便它对我也有价值而非噪音。
17. 作为出厂包用户，我希望出厂包页拖起文件时行不显示目标高亮，以便界面不谎称可写。
18. 作为出厂包用户，我希望在出厂包行上松手时得到与点击路径相同的「复制为我的包」引导，以便拖与点行为一致。
19. 作为工作区用户，我希望「默认组／工作区」页的行尾 chevron 入口保持现状，以便已学会的入口不变化。
20. 作为用户，我希望试听与静音仍是行内按钮、不进任何新菜单，以便每个动作只有一个入口。
21. 作为中文/英文用户，我希望所有新文案双语一致且占位符相同，以便界面语言统一。
22. 作为维护者，我希望新行为的回归测试注册进两个既有测试 harness，以便后续改动不破坏合同。

## Implementation Decisions

讨论定稿的八项决策（全部与已拍板决定相容）：

- Q1 入口形制：面板事件行的身份区升格——声音文件名即入口；不做右键菜单（维持 2026 年否决）。
- Q2 动作语义：深链进同窗口「声音」目的页；面板不新增任何写路径。复用恢复链接今天使用的同一深链编排（用户包定向编辑、出厂包定向复制并编辑），面板行只是该编排的新调用方。
- Q3 拖放：只挂「声音」目的页事件行；drop 语义 = 打开导入流程的预览态（预填文件），显式「选用」才绑定；不做 drop-to-bind，不落面板行。
- Q3a 可发现性：常驻导向说明行独揽教学（仅用户声音包详情页）+ 拖拽目标高亮/浮标；导入 sheet 内不放教学行（同一事实一个归属）；不做一次性教练气泡。
- Q4 单动作：入口无菜单、无下拉箭头；动词由 tooltip/无障碍标签承载并按包性质切换（更换声音…/查看声音…）。
- Q5「默认组／工作区」页不动（行尾 chevron 已是带 return context 的深链）。
- Q6 深链落点为聚焦事件行，到达时不程序化弹出菜单或 sheet（不假设意图；焦点位置可预测）。
- Q7 出厂包：行不注册为拖放目标、不亮高亮；松手复用与点击路径相同的「复制为我的包」引导；导向说明行不出现在出厂包页。

模块与界面改动（只列模块，不列文件）：

- ClaudioPanelPresentation：事件行的声音名从展示文本变为按钮；行呈现投影（PanelEventPresentation）新增「声音入口」事实——可用性、目标路由、tooltip 键；视图只读投影，不自行判断包性质。行内试听与静音按钮不变。
- ClaudioGUI（菜单栏控制器接线）：为面板行新入口接既有的声音深链闭包（恢复链接同一条 typed route 编排）；不新增路由类型。
- ClaudioSettingsPresentation（「声音」目的页）：包详情事件行挂拖放目标；用户包详情页渲染导向说明行；出厂包页不渲染说明行、行不接受拖放。
- ClaudioGUICore：声音事件选择会话（SoundEventSelectionSession）新增「从给定文件 URL 进入本地导入预览」入口——跳过文件选择面板，其余与既有本地导入流程完全一致（同一硬化校验、同一预览态、同一「选用」提交）；声音页呈现投影按包可编辑性暴露「行是否接受拖放」。
- 复用而不改动：拖放 URL 装载、音频导入硬化管线（路径/大小/魔数/时长四道校验）、packs.lock/CAS 写边界、全应用唯一的手动试听会话（ADR 0028：一次一个试听，离开发起面即停）。
- 路由合同不变：深链目标携带稳定 packID + Event；stale 目标 fail-closed 到可见错误，不静默重定向。
- 本地化：新增文案键（tooltip×2、导向说明行、拖放浮标、出厂包引导如缺）需英文与 zh-Hans 条目、占位符一致，并注册进 ClaudioL10nKey.allKnown。
- 文档修订：PLAN-NATIVE-PROTOTYPE-MIGRATION 的 P4「删正常文件名」条目加注——文件名行在面板保留，角色从装饰信息变为入口载体（修订理由随本次变更记录）。无新 ADR（未反转任何已拍板决定）；CONTEXT.md 无新术语。

## Testing Decisions

好测试只测外部行为（呈现投影暴露的事实、会话的外部状态），不测 SwiftUI 视图内部。既有 seam 优先，不开新 seam：

1. **面板呈现投影 seam**：给定健康事件与包性质（用户/出厂），断言事件行投影暴露声音入口、目标路由（编辑 / 复制并编辑）与 tooltip 键；焦点顺序包含新按钮。命中目标：入口按钮复用预览恢复链接的 link 样式与尺寸先例（该先例本无自动断言），命中目标合规列入人工门（真实面板走查），不为它在 HitTargetSuite 开新 fixture（2026-10-17 复审修订）。先例套件：PanelSoundScopeInteractionSuite、PanelMountedContractSuite、PanelPresentationMountSuite、PanelFocusOrderSuite。
2. **选择会话 seam**：给 SoundEventSelectionSession 新入口喂文件 URL，断言进入与文件选择面板路径一致的预览态；取消保留旧绑定；「选用」走既有提交。先例套件：SoundEventSelectionLifecycleSuite、SettingsSoundsSheetLayoutSuite。
3. **声音页呈现投影 seam**：按包可编辑性断言行拖放可用性与说明行可见性；出厂包 drop 路由到「复制为我的包」引导。先例套件：SettingsSoundsPublicationSuite、SettingsSoundsLayoutSuite、SoundPacksEditorViewSuite（既有 test-only 拖放挂载）。
4. **跨文件合同**（行 → 深链闭包接线）按 AGENTS.md 仅对无法编译表达的部分用最小 source-wiring 检查。先例：ViewWiringSuite。
5. **本地化**：LocalizationSuite 注册检查 + `jq empty` 校验目录。

新套件按 `<Feature>Suite.swift` + `run<Feature>Suites()` 惯例注册进 gui 包测试入口；helper 零改动、无 helper 侧测试。验收门槛：`swift run --package-path gui claudio-gui-tests`、`swift run --package-path helper claudio-tests`、jq 本地化校验、`git diff --check`。

人工门（harness 覆盖不了，交付时如实标注未验证）：真实访达拖拽手感与目标高亮时机、tooltip 行为、键盘/VoiceOver 完整路径、出厂包「复制为我的包」引导的实际点击流、真机音频试听。

## Out of Scope

- 右键菜单（维持否决：不可发现 + WCAG 2.1.1）。
- 面板内直接更换包事件声音来源（第二写路径，违 ADR 0005/0008/0021 与单一 owner 原则）。
- 面板行拖放、drop-to-bind（绕过预览与显式选用）。
- 「默认组／工作区」页的手势统一（chevron → 文件名链接）：可行的后续小改，不在本次。
- 深链到达时自动弹菜单/sheet；导入 sheet 内的步骤压缩（如记住上次来源）。
- 导入 sheet 教学行、教练气泡、自毁 hint。
- AI 提示音候选/生成流程的任何改动。
- 原型 HTML 的清理（留作决策证据至实现落地）。

## Further Notes

- 步数账：换声音 6–8 步 → 5 次点击（零导航步）；导入 1 拖 + 1–2 次点击；面板新增写路径为零。
- 归属纠正：深链合同来自 ADR 0008 的 typed route 与 PLAN-NATIVE-PROTOTYPE-MIGRATION 的 return context；ADR 0022 只管窗口焦点机制。原提案「复用 ADR 0022 深链编排」的直觉（复用既有编排、成本低）正确，归属有误。
