# 事件动画接入规格

## Problem Statement

三组角色已在 Pixel Motion Prototype 中打磨完成，但旧导出资源和动画设置原型的画面及逐帧时长不一致。机械小鸭还需要分别呈现浅色、深色画面。直接接入旧数据会丢失已确认的视觉效果和动作节奏。

## Solution

以打磨后的 Pixel Motion Prototype 为角色画面、逐帧时长、循环范围和静态帧的唯一准据。在原生统一设置窗口的「通知 → 事件动画」中并排提供原版图标、机械小鸭、像素幽灵、比特币四种选择，默认原版。设置预览与真实横幅使用相同资源和播放器。由 Codex 自动完成资源、行为、原生操作、截图及适用工程验证，不另设人工验收关卡。
> **2026-10-07 注**：Pixel Motion Prototype.html 已随原型合并删除；samples/ 资产与导出脚本保留，本条"唯一准据"的文件指向待重新指定。
> **2026-10-09 来源修复**：从删除前 Git blob 按原字节归档到 [source/Pixel Motion Prototype.html](../designs/pixel-motion/source/Pixel%20Motion%20Prototype.html)，SHA-256 与下述已导出资源来源一致。此路径是导出／回归的固定输入；当前原生 UI 仍遵循 DESIGN，不恢复旧原型为当前界面。

## User Stories

1. 作为用户，我希望角色与打磨后的原型一致，以便保留确认的画面。
2. 作为用户，我希望五种事件动作保持定稿节奏，以便看到正确的情绪表达。
3. 作为用户，我希望从通知设置进入事件动画，以便容易找到功能。
4. 作为用户，我希望使用 macOS 原生控件，以便保持一致的操作体验。
5. 作为用户，我希望并排比较四种样式，以便直接选择。
6. 作为用户，我希望保留原版静态图标，以便继续使用熟悉的表现。
7. 作为升级用户，我希望默认保持原版，以便升级不会突然增加动画。
8. 作为用户，我希望选择立即保存并生效，以便明确当前设置。
9. 作为用户，我希望重启后保留选择，以便无需重复设置。
10. 作为用户，我希望预览五类事件，以便了解不同动作。
11. 作为用户，我希望随时重播，以便比较细节。
12. 作为用户，我希望预览不触发声音、真实提示或宿主操作，以便放心尝试。
13. 作为用户，我希望关闭角色显示时保留选择，以便随后恢复。
14. 作为用户，我希望只显示静态表情，以便减少动态干扰。
15. 作为用户，我希望遵循系统减少动态效果，以便符合辅助功能偏好。
16. 作为用户，我希望浅色和深色外观符合定稿，以便切换外观后画面正确。
17. 作为用户，我希望动画保留横幅阅读和跳转行为，以便操作习惯稳定。
18. 作为用户，我希望资源异常仍显示原版图标和恢复入口，以便通知可用且选择不会丢失。
19. 作为用户，我希望通过键盘完成操作，以便无需鼠标。
20. 作为用户，我希望中英文和两种窗口尺寸清晰，以便正常使用。
21. 作为用户，我希望不可见时停止动画计算，以便减少资源占用。
22. 作为维护者，我希望自动检查资源与原型一致，以便发现过期导出物。
23. 作为维护者，我希望自动验证原生交互，以便无需逐项人工测试。
24. 作为维护者，我希望报告绑定实际候选构建，以便准确判断验证结果。

## Implementation Decisions

- 源原型完整 SHA-256 为 `447509d637fef2e11bb8c3c65e249476bc8dbd127f771fa219729b428ded22fc`。直接复用其 `statesFor`、`atlas`、`manifest`、`frameAtElapsed` 导出，不手绘或维护第二份时序数组。先写临时目录并校验，随后只替换明确属于三组角色的导出物和来源清单。保留其他工作树改动。
- 保留七行图集；产品预览只开放五个公共 Event，`idle` 供中立静态呈现，`preview` 不接入声音。机械小鸭分别导出明暗图集；幽灵和比特币经像素一致性验证后各共用图集。来源清单包括原型指纹、外观映射、资源校验值和时序。正式应用只打包图集、时序及清单。设置原型读取同一导出数据。
- 五个动作首轮时长（机械小鸭／像素幽灵／比特币，毫秒）：`task_start` 1740／2105／1610，`notification` 1885／2280／1170，`stop` 2120／2280／2225，`subagent_stop` 1980／2130／1200，`stop_failure` 2040／2190／2425。实际解析直接使用导出数据。
- 2026-10-06 用户授权改为横幅展示期间循环。小鸭与幽灵五类事件均完整循环零起算帧 0–15，沿用末帧 420–540ms 的短停顿，不新增时序数组。比特币开始和子任务结束完整首轮后循环帧 8–15，待响应循环 0–15；结束和中断完整循环帧 0–15，保留末帧 520／600ms 的短停顿。`idle`／`preview` 小样保持原声明，产品中立画面仍静态。静态模式使用声明的 `reducedMotionFrame`。原型循环演示开关及额外 650ms 演示停顿不进入产品规则。
- `EventAnimationStyle` 包括 `original`、`mechanicalDuck`、`pixelGhost`、`bitcoin`。`EventAnimationPreferences` 包括样式、角色显示、静态表情，默认原版／开启／关闭。由唯一 `ClaudioPreferences` 保存并发布，独立键为 `Claudio.Notifications.EventAnimation`。缺失使用默认值；损坏或不支持配置投影为原版，保留原始字节直到用户明确重新选择。
- 在现有 `SettingsPresentationSession` 和类型化路由增加通知的事件动画子页，不创建新窗口或事实 owner。选择角色开启显示；关闭显示使用原版并记住选择，原版隐藏角色开关；通知总览显示有效样式。保留当前原生设置设计和 A 并排布局。
- GUI executable 拥有运行资源，通过依赖注入交给共享组件与设置；设置 target 无资源所有权。Foundation core 负责确定性帧解析，共享 `EventAnimationView` 呈现透明、最近邻缩放的约 32 pt 角色，原版复用 `ClaudioEventGlyph`。按需后台读取、解码、有界缓存，播放中不读磁盘。外观切换保持进度，资源异常回退原版，设置显示原因和重试，选择保留。
- 预览使用同一横幅内容组件；独立演示状态属于设置会话，不写真实 `EventNoticeModel`。样式、事件和重播重启四秒预览；结束保留静态画面，离页和关闭停止调度。预览不发声音、真实提示、宿主动作。
- 真实动作由公共 Event 和规范化原因决定。权限请求、明确输入请求使用待响应，普通消息和 `questionIntent` 保留现有语义并使用中立静态画面。动画进度派生自现有四秒阅读预算，悬停／焦点同步暂停；重绘、重试、样式及外观变化不重置预算。循环仅在可见且阅读预算尚未耗尽期间运行，悬停／焦点暂停、静态模式、离页和关闭停止调度。保持来源跳转、反馈、提醒保留期限和非激活窗口，不从动画推断任务状态。
- Reduce Motion 或静态开关使用声明静态帧。新增文案双语注册，装饰角色不重复参与辅助功能朗读。

## Testing Decisions

- 最高集成接缝为生产 `SettingsRootView`／`SettingsPresentationSession` 与共享横幅内容，通过现有依赖注入、隔离偏好和原生 fixture 测试用户可观察行为。新增注册 `EventAnimationIntegrationSuite`；使用既有原生回归和 Computer Use 驱动。
- 比较三角色 × 五事件 × 16 帧 × 两外观的 480 个参考帧：HTML 直接绘制与包内解码一致，全部逐帧时长、静态帧、播放模式、循环范围一致。由 HTML `frameAtElapsed` 生成各边界前后、首轮末尾和后续循环参考，与生产解析器对照。验证源更新会拒绝旧资源。
- 覆盖非产品单次小样末帧、五类事件完整重播与部分循环衔接、暂停恢复、静态、外观切换、四种选择、五事件、立即保存、重启持久化、开关、异常回退、重试、预览隔离和离页清理。只测外部合同，不用镜像实现的测试替代资源来源验证。
- 原生自动操作覆盖点击、键盘、Tab、返回及焦点恢复，每次操作重新读取 AX 状态并核对偏好。四样式 × 双语 × 明暗 × 两窗口尺寸共 32 组布局，Codex 检查截图裁切、重叠、选中态、缩放和角色画面，生成截图本身不算通过。
- 运行 helper/GUI executable harness、GUI 与设置 target Debug/Release 构建、本地化、bundle、体积预算、差异检查。统一设置门禁保留干净候选要求，不清理共享工作树或弱化检查。先探测桌面、窗口、截图、输入能力，可恢复启动问题重试一次。
- 产品错误记录 `FAIL`，环境问题记录 `BLOCKED`；未运行必测项不记通过。报告绑定源码、原型、资源、bundle 指纹与运行环境。全部适用门禁通过才标记完成。

## Out of Scope

重新设计角色／调整节奏，菜单栏／Dock／桌面宠物／持续任务／提醒列表动画，声音配置、宿主协议、自定义主题、工作区单独动画，原型布局切换器／循环演示开关／HTML 嵌入，无关资源清理、推送、正式发行、签名公证、关闭 Issue。

## Further Notes

原型决定动画内容，原生设置设计决定布局，既有领域模型决定真实触发语义。VoiceOver 朗读、真实听感和真实宿主回调未覆盖时保持 `NOT VERIFIED`，不增加为本功能完成条件。原型及本规格不等于实现、原生验证或发行证据。
