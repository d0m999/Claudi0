# Claudio 整合原型的完整原生迁移规格

## Problem Statement

已确认整合原型与原生面板、八页设置和横幅仍有呈现差异。设计文档与 ADR 的详情入口、声音包称呼及侧栏顺序需统一，避免后续采用不同合同。

## Solution

以整合原型为呈现基线，在既有 owner、领域、安全及持久化合同上完成原生迁移，删除整包导入演示，提供隔离原生自动点击检查，并分开记录自动、人工和外部证据。

## User Stories

1. 菜单栏用户首先看到「需要你」数量和最新事项，快速判断是否接手。
2. 用户在面板展开保留提醒列表。
3. 用户在面板内查看来源、时间和会话详情。
4. 用户阅读静态横幅正文。
5. 用户通过语义动作打开已确认来源应用。
6. 用户关闭或等待横幅收起后仍能稍后接手。
7. 用户悬停或聚焦横幅时暂停阅读倒计时。
8. 用户失败重试沿用剩余阅读时间。
9. 用户看到就地失败原因和重试。
10. 来源未确认时用户获得真实可用的面板查看入口。
11. 打开应用后提醒仍保留，不推断处理完成。
12. 普通进展和即将提问只瞬时展示。
13. 阅读中的提醒保持顺序。
14. 旧版本明确提示刷新，动作对应所见版本。
15. 过期提醒清除来源与时间。
16. 用户可复制有效会话 ID。
17. 移除提醒只表示用户的移除操作。
18. 声音作用域由用户选择，不受最近回调影响。
19. 面板事件行只呈现熟悉名称。
20. 试听不可用时用户看到原因及恢复入口。
21. 关闭自动播放不影响手工试听。
22. 试听结果对应播放器实际启动状态。
23. 面板只显示今日和近七日五事件总数。
24. 详细活动集中在设置。
25. 所有设置入口进入同一 retained 窗口。
26. 设置页有清晰页头、区块及控件间距。
27. 最小窗口内内容、错误和操作可滚动到达。
28. 声音与工作区采用一致纵向五事件卡片。
29. 工作区编辑声音后恢复原作用域、音量、开关及事件焦点。
30. 容器统一称声音包，单个声音称提示音。
31. 编辑共享包前展示使用者。
32. 内置包通过复制后编辑。
33. 内置包不展示生成入口。
34. 文件、系统音、音频导入和清除绑定共用编辑入口。
35. AI 服务能力、凭据状态和候选数反映实际路线。
36. 生成期间描述锁定，取消后恢复。
37. 改名不重新生成，采用失败保留旧绑定。
38. 权限、隐私、费用和后果位于对应控件附近。
39. 键盘和 VoiceOver 用户获得焦点、名称、禁用原因和结果反馈。
40. 维护者用当前构建和隔离数据重复原生点击检查。

## Implementation Decisions

按 P0→P1→P2→P3→P4→P5→P6 执行，各阶段同步回归。

- P0：固定源码和原型指纹，保留基线既有 Swift 焦点、Python 回归、未跟踪脚本及旧横幅原型删除。删除原型整包导入按钮、确认、演示创建及绑定。修订 DESIGN、设置计划、ADR 0008/0016/0019 和词汇，保留历史覆盖关系。
- P1：八页顺序为默认组／工作区、声音、集成、通知、通用、快捷键、活动与诊断、关于。侧栏与键盘共用顺序，raw values 和历史 display 兼容保留。默认 1240×820、最小 960×640；侧栏 210/252pt 断点不变，内容约 820pt。页头和区块间距 36pt、普通控件行至少 64pt，多行自然增高。内容不足 760pt 辅助卡置于事件之后，宽窗口 260pt 辅助栏。通知按横幅、自动静默、当前状态分组，权限与隐私贴近控件，删除重复和实现文案。保留 accessory 策略、非激活焦点和唯一窗口。
- P2：完整真实包库和规则的顶部选择器，下面统一纵向五事件卡。声音辅助栏为既有 AI 服务，工作区为目录、来源和规则操作。工作区编辑定向进入同窗口包与事件，不启动 AI。SettingsPresentationSession 保存类型化返回上下文，重验规则身份并恢复事件焦点；失效显示失败，禁止落到可写默认组。复用试听序列，零音量／无可用事件显示原因，切换和离页停止播放。内置包查看、试听、复制编辑、恢复；普通复制不改选包，复制并用于继续验证目标。保留去重、锁/CAS、草稿发布、使用者披露、删除保护和失败保旧值。
- P3：EventNoticeModel 唯一持有提醒事实，独立发布横幅与阅读投影。面板和诊断共享最多 50 项冻结集合，首个消费者冻结、显式刷新、末个消费者关闭后释放。视图只保存展开和选中动作身份。SessionNavigationCoordinator 在组合根共享，单在途、版本/epoch/能力代次、3 秒超时不变。横幅收起与阅读关闭独立，面板/诊断不暂停或重置横幅；横幅自身悬停/键盘聚焦暂停，TTL 独立。
- P4：横幅静态正文，无详情、正文按钮、展开或返回；关闭和 4 秒轨始终保留，失败/重绘/重试不重算。已确认来源显示去授权／去输入／去查看，未确认提供在面板查看并定位提醒。失败就地原因，有效动作重试，更新/过期禁用并提示需要你。成功仅收横幅、消费焦点归还责任并保留提醒，无 exactReturnConfirmed。面板需要你置顶，列表/详情内嵌，Escape 按详情→列表→收起阅读→关闭面板。事件行仅图形、用户名称、试听和自动开关，异常可见，删正常 ID/文件名/装饰波形。底部共享活动投影的所有来源今日/七日五事件总数，无范围切换或活动展开。诊断新增默认折叠待处理事件记录，安全来源、绝对时间、相对年龄、有效会话复制；仅内存投影，不写日志/摘要，清日志/计数不清提醒。
- P5：复用五固定 profiles、路线能力、凭据和操作投影；描述校验/锁定/取消、route-owned 候选/partial、改名不生成、显式采用/失败回滚保持。离页/关闭/切包/profile 清理未采用候选与试听，不新增网络、费用或凭据路径。English/zh-Hans、占位符和 allKnown 同步。公共接口仅双投影/阅读生命周期、导航注入、返回上下文、编辑布局插槽。schema、事件、hook、manifest/config、凭据政策与路径不变。
- P6：专用 DEBUG bundle com.claudio.app.ui-regression，显式 fixture 标记，正常 bundle/Release 无入口。生产 owner 创建前选择隔离组合，临时 config/包/活动/defaults，真实视图/模型/写入；Provider、凭据、安装、应用打开为确定性替身，单调时钟可推进，控制仅固定场景。mcp__cua_repl JavaScript 根据当前 AX 定位，每步重新读，不复用索引。导航/选择/返回/生成取消采用/提醒复制移除/失败重试/窗口关闭均检查最终状态和副作用。逐用例、AX、截图绑定源码/工作树/bundle/macOS/架构。接口或控件不可用及结果缺失判失败或阻塞，不计通过。独立于无桌面 CI。

## Testing Decisions

使用既有 SettingsPresentationSession、SoundPacksEditorOwner、EventNoticeModel、SessionNavigationCoordinator 最高行为接缝；测试状态、反馈和磁盘结果，不绑定私有结构。suite 按仓库命名/注册，源码检查限无法编译表达的跨文件合同。挂载沿用现有布局探针。

必须覆盖路由与返回的切包/删规则/失效深链/异步漂移；试听与自动正交/原因/序列取消/写失败保旧值；横幅累计 4 秒/暂停/失败不重置/成功留提醒/迟到回调不抢焦点；冻结/刷新/旧版本/容量/TTL/隐私/多入口关闭；活动同源五事件总数与三种清理独立；AI 路线/partial/描述锁定/清理/采用/草稿；双语占位符/注册；原型整包导入彻底删除且其他交互通过。

原生矩阵：八页 × 2 语言 × 2 外观 × 2 尺寸（8 组）；完整流程至少简中/浅色/默认和 English/深色/最小。固定异常：空库、陈旧、损坏、零音量、失效工作区、重复映射、AI partial/失败、提醒更新/过期、跳转失败/超时。替身不证明真实应用激活或 Provider 调用。

人工分别验收布局、真实键盘、VoiceOver、Reduce Motion、Increase Contrast、实际听感、真实来源激活；真实 Provider 请求需单独授权。

执行原型 Node、helper/GUI executable harness、GUI Debug/Release、本地化 JSON、diff；独立执行原生点击、bundle/大小。完整 verify-settings-experience.sh 使用固定基线，仅在获准提交后的干净候选执行。条件未满足标记总门禁未完成，关键原生检查未完不宣布完整迁移验收通过。

## Out of Scope
